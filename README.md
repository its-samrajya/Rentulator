# Rentulator

A rental property management app for small landlords and their tenants. Track rooms and electricity meters, generate rent + electricity invoices, record payments, and let tenants pay online through eSewa.

Supports Nepali dates (BS).

## Features

**Admin**

- Dashboard with monthly revenue, pending invoices, and room occupancy
- Manage rooms, electricity meters, and tenants
- Record meter readings and generate invoices (rent + electricity)
- Record cash/bank payments and print receipts
- Send WhatsApp payment reminders
- Invite tenants with a shareable link

**Tenant**

- View current room, unpaid invoices, and payment history
- Pay invoices through eSewa

## Tech Stack

- Next.js (App Router), React, TypeScript
- Tailwind CSS, shadcn/ui
- Prisma, PostgreSQL
- Auth.js
- Resend (emails)
- eSewa (payments)
